# ChillChain demo walkthrough (about 8 minutes)

Use up to **four accounts** (one per role) in different browsers or private windows. All payments are test payments; please don't enter real ID or bank details. A valid test Aadhaar for driver documents is `234123412346`.

Story: a strawberry grower near **Mahabaleshwar (Satara)** and a quick-commerce buyer in **Pune**.

## Buyer first (1 min)

1. **Buyer** → create account → buyer type **Quick-commerce / dark store**.
2. **Pre-orders** → 200 kg strawberry, grade A, ₹160/kg, needed in 3 days, deliver to Pune → **Post pre-order**.

## Grower (4 min)

3. **Grower / FPO** → create account → profile in **Maharashtra → Satara**.
4. **Home** shows the **Sell-by clock**, **Buyer demand** (the buyer's pre-order) and market rates. Switch **हिंदी / English**.
5. **Sell → Buyer demand** → **Accept & lock price** → the money is in escrow before harvest.
6. **Home → Scan a lot** → Strawberry, harvested **4 hours ago**, **Open air** → **Simulate scan**. The certificate shows grade, ripeness and a big **"Sell within …"** clock with the best next step.
7. Tap **Pre-cool now (by the hour)** → the Storage tab opens on **Pre-cooling** → Mahabaleshwar Berry Pre-cool Hub → **By the hour**, 4 hours → book. Scan again with **Cooled** to see how much longer the fruit now lasts.
8. Back on the certificate → **Book reefer before deadline** → the deadline is filled from the clock → **Share a truck** → Satara to Pune → **Join a shared truck** (you pay only your share).
9. **List for buyers** on another scan to put a lot on the open market.
10. **Plan → ProfitPlanter** → try *Semi-arid plateau, 2 acres, ₹10 lakh, low water* vs *Cool hills, plenty of water* and watch dragon fruit / pomegranate swap with kiwi / strawberry.

## Buyer, transporter, storage owner (2 min)

11. **Buyer → Market**: lots show a clock, a channel (Premium retail / Flash sale / Processor) and the live price. Order one → **My orders** → confirm delivery with the grower's code (grower's **Money** tab).
12. **Transporter** → add a **Reefer mini van** → **Verify later** → the shared load shows "Shared load POOL-…" and a **Deliver by** badge → accept (takes the whole pool) → picked up → delivered.
13. **Storage owner** → register a **Ripening chamber** with day and hour rates.

## Ratings (1 min)

14. Each side now sees **"Rate N completed deals"** (ChillScore). The farmer → driver rating includes **Delivered before the deadline**, worked out from the trip record.
